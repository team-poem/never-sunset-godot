# 해가 지지 않는 동 · 104

익숙한 집의 흠집을 기억하고, 지나치게 완벽해진 물건들을 발견하는 Godot 4.7.2 기반 1인칭 이야기 공포 게임입니다. 시작부터 세 결말까지 연결된 짧은 작품입니다. 예상 플레이 시간은 약 15분이며, 실측 평균은 아닙니다.

[English](README.md)

## 실행

Godot 4.7.2에서 `project.godot`을 열고 `scenes/main.tscn`을 F6으로 실행하거나 `npm start`를 실행합니다. 이 컴퓨터에서는 프로젝트 내부에 받은 공식 macOS 엔진을 사용합니다. 다른 컴퓨터에서는 Godot을 설치해 `godot`을 PATH에 등록하거나 `GODOT_BIN`에 실행 파일 경로를 지정하세요.

- WASD로 이동하고 마우스 또는 방향키로 시선을 움직입니다. 마우스 고정이 안 되면 왼쪽 버튼을 누른 채 드래그하세요.
- 사물을 조준하고 E 또는 왼쪽 클릭으로 살펴봅니다.
- 든 컵은 드래그나 방향키로 돌리며 Esc로 내려놓습니다.
- J는 기억 수첩, Esc는 일시정지 및 설정, F는 전체 화면입니다.
- 환경음과 시점 흔들림을 끌 수 있습니다. 필수 소리 단서는 글로도 제공됩니다.

데스크톱 키보드와 마우스용입니다. 터치 조작은 구현하지 않았습니다. 진행 기록은 현재 컴퓨터 사용자 또는 브라우저의 해당 사이트에 저장됩니다. 사이트 데이터를 삭제하면 기록도 사라집니다. 서버, 계정, 분석 추적 기능은 없습니다.

## 구성

아파트 한 세대, 대피 계단참, 열쇠를 고르는 공간과 결말 공간을 만들었습니다. 컵·사진·문틀의 흔적, 빛, 배수구, 월패드, 욕실 맥박이 이야기 단계에 맞춰 바뀝니다. 1994년 공사 기록은 선택적으로 읽을 수 있고 결말은 세 가지입니다. 기존 HTML 게임은 별도 `../never-sunset` 프로젝트에 보존했습니다.

직접 만든 단순한 3D 형상과 절제된 환경음, 한글 서술을 사용합니다. 음성 연기, 추격, 전투, 점프스케어는 없습니다. 전망형 엘리베이터는 문 앞에서 볼 수 있는 선택 장면으로 구성했으며 실제 승강 이동은 구현하지 않았습니다.

## 웹 빌드와 공유

공식 Godot 4.7.2의 단일 스레드 웹 템플릿을 `.tools/web_nothreads_debug.zip`, `.tools/web_nothreads_release.zip`에 놓습니다. 출처와 체크섬은 `ASSET_SOURCES.md`에 있습니다.

```sh
npm run export:web
npm run serve
```

데스크톱 브라우저로 http://localhost:4174 를 엽니다. 이 주소는 현재 컴퓨터에서만 열립니다. 일부 앱 내부 브라우저는 마우스 고정을 거부하므로 일반 브라우저 창을 권장합니다.

빌드는 라이선스가 포함된 `build/web/` 폴더와 `build/never-sunset-web.zip`을 생성합니다. **build/web 안의 파일 전체**를 Netlify나 Vercel 등의 정적 호스팅에 함께 올리면 됩니다. 서버 함수는 필요하지 않습니다. 현재 공개 배포나 클라우드 자동 빌드 연결은 하지 않았습니다. 빌드 결과와 엔진은 Git에서 제외하므로 Git 연결 배포에는 별도의 Godot 빌드 단계가 필요합니다.

단일 스레드 Compatibility/WebGL 2 빌드라 교차 출처 격리 헤더는 필요하지 않습니다. 공개 서버는 HTTPS와 `.wasm`의 `application/wasm` 형식을 사용하세요. HTML 파일을 직접 더블클릭하는 `file://` 실행은 지원하지 않습니다. 처음 받는 엔진과 게임 데이터는 비압축 약 44MB이며 호스팅 압축을 적용하면 전송량이 줄어듭니다.
