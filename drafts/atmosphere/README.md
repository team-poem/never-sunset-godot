# 몰입형 공포 개선안 — 승인 대기

현재 게임 코드는 변경하지 않았습니다. 이 폴더는 다음 루프의 변경 범위, 실행 가능한 테스트 초안, 기존 검사 한 건의 교체안을 담습니다. 사용자의 원문 spec.md와 기존 테스트·검사 계획은 그대로 보존했습니다.

## 플레이 변화

1. 귀가와 일반 관찰은 화면 아래 짧은 자막으로 이어집니다. ‘계속’ 버튼 때문에 걷기와 시선이 멈추지 않습니다. 긴 설명은 수첩과 직접 펼쳐 읽는 공지·감리 일지에 남깁니다. 자막이 연달아 생겨도 중요한 내용은 순서대로 읽히며 저장 후 복원됩니다.
2. 컵을 실제 시야 앞에 들어 살펴봅니다. 이동과 주변 환경은 계속되고, Esc로 내려놓으면 관찰이 기록됩니다. 사진과 문틀은 가까이 조준하여 바로 관찰합니다.
3. E는 현재 사물의 기본 행동, Q는 위험한 대체 행동입니다. 커튼을 당기는 동안 천이 움직이고, 냄비가 배수구 위로 옮겨지며, 월패드 전원은 약 3초에 걸쳐 꺼집니다. 반복 입력으로 같은 결과·소리가 중복되지 않게 합니다. 물·벽의 맥박도 변화가 눈과 귀에 보이도록 구성합니다.
4. 기본 환경광은 현재 0.42에서 0.05~0.18 범위로 낮춥니다. 현관·식탁·욕실의 제한된 광원, 실외 붉은빛과 어두운 구석의 대비를 사용합니다. 실제 시야각은 기존 68도를 유지합니다. 단순히 화면 전체를 검게 덮지 않습니다.
5. 문틀의 키 재는 선은 원래 위치에 유지하고, 부분 조명과 조준 범위를 넓힙니다. 어두워져도 필수 단서 탐색이 더 불편해지지 않게 실제 화면에서 확인합니다.
6. 무료 재질의 색·노멀·거칠기 맵을 벽·마루·타일에 적용합니다. 기존 가구의 모서리·손때·생활 흔적을 보강해 에셋 간 스타일을 맞춥니다. PC 웹 빌드에 맞춰 1K 재질을 우선 사용합니다.
7. 무료 생활 효과음을 컵·발걸음·커튼·문·종이 등 동작과 연결합니다. 배수구·냉장고·벽의 낮은 지속음은 기존 합성음과 함께 구성합니다. 소리는 해당 사물 위치에서 들리고, 갑작스러운 큰 소리와 점프스케어는 넣지 않습니다.
8. 내가 멈춘 뒤 한 번 더 나는 발소리, 천천히 들썩이는 냄비, 닫은 커튼 아래 남는 빛, 맥박에 따라 미세하게 움직이는 표면처럼 ‘설명 전에 발견할 수 있는’ 장면을 강화합니다. 세계관과 세 결말은 유지합니다.

## 승인 대상

- `failed-test-draft.md`: 11개 테스트의 전체 코드와 공통 헤더.
- `scene_probe.gd`: 실제 Godot 장면을 실행하는 공통 검증 코드.
- `legacy-test-replacement.patch`: 기존 PendingOutcome 테스트와 그 계획 항목을 제거하고 PendingOutcomeV2로 교체하기 위한 정확한 변경안. 나머지 기존 13개 테스트는 그대로 유지합니다.
- 이 문서의 플레이 변화와 아래 수동 완료 기준.

기존 PendingOutcome 테스트는 저장 복원 시 `mode == 'dialog'`를 요구합니다. 이번 요청의 ‘설명창으로 멈추지 않기’와 직접 충돌하므로 교체 승인이 필요합니다. V2는 저장 내용 보존, 자연스러운 자막 종료, 복원 후 이동 가능을 함께 검사합니다. 기존 테스트를 몰래 완화하지 않습니다.

승인 후에는 이 교체안을 반영하고, 새 테스트 초안을 failed-test.md에 합친 뒤 현재 하네스에 정확한 승인 기준을 등록합니다. `loop.sh`가 한 항목씩 테스트 삽입·실행·검증·커밋을 맡고, 최종 gate와 별도 검토를 거칩니다. 이번 확인에서 기존 앱에는 새 하네스의 승인 기준이 아직 없었습니다.

## 실행한 초안 검증

11개 모두 실제 Godot 장면에서 의도한 단언 실패(RED)를 확인했습니다. 구문 오류·의존성 오류·스크립트 오류를 실패 근거로 사용하지 않았습니다. 자세한 결과는 PROBE_RESULTS.md에 있습니다. RED는 현 버전에 기능이 없다는 증거이며, 구현 완료가 아닙니다.

## 수동 완료 기준

- 최종 웹 빌드를 열고 귀가부터 세 결말 경로를 검토합니다. 필수 진행에 ‘계속’ 설명창이 끼어드는 지점을 제거합니다. 플레이어가 직접 펼치는 문서, 설정, 끝 화면은 예외입니다.
- 같은 위치의 개선 전후 화면을 비교합니다. 어두운 구석과 국소 조명의 대비가 생기고 문틀·컵·사진은 찾을 수 있어야 합니다.
- 무료 재질이 실제 표면에 보이는지, 동작별 소리가 위치에 맞게 들리는지 확인합니다. 음소거와 시점 흔들림 설정은 계속 동작해야 합니다.
- 컵·커튼·냄비·월패드·벽의 변화가 설명 자막보다 먼저 또는 동시에 전달되는지 별도 검토합니다.
- 기존 13개 보존 테스트와 11개 새 테스트가 통과해야 합니다. 단일 스레드 Web 내보내기, 배포 ZIP, 라이선스 목록과 실행 안내를 갱신합니다.

예상 플레이 시간·공포 반응·미술 완성도는 자동 테스트 숫자로 증명하지 않습니다. 최종 화면과 플레이 검토 근거를 함께 보고합니다.
