# 웹 수동 검증 기준 변경안 — 미승인

구현과 배포 ZIP은 준비되었으나, 승인된 브라우저 세 결말 완주는 완료하지 못했습니다. 이 문서는 기준 변경 제안이며, 기존 승인 문서와 테스트는 그대로입니다.

## 변경할 문장

`drafts/atmosphere/README.md`의 첫 번째 수동 완료 기준:

> 최종 웹 빌드를 열고 귀가부터 세 결말 경로를 검토합니다. 필수 진행에 ‘계속’ 설명창이 끼어드는 지점을 제거합니다. 플레이어가 직접 펼치는 문서, 설정, 끝 화면은 예외입니다.

## 제안하는 대체 문장

> 최종 웹 빌드에서는 시작·저장 이어하기·문틀 관찰·드래그 시선·설정과 음소거를 실제 브라우저 UI로 확인합니다. 귀가부터 세 결말로 이어지는 행동 분기와 설명창 없이 진행되는지는 실제 Godot 장면의 컨트롤러·키 입력 진단으로 확인합니다. 플레이어가 직접 펼치는 문서, 설정, 끝 화면은 예외입니다. 브라우저에서 직접 걸으며 세 결말까지 완주하는 검증은 이번 루프의 완료 조건에서 제외하고 미검증으로 명시합니다.

나머지 수동 기준, 승인된 24개 테스트와 검증 코드는 변경하지 않습니다. 추가 38개 장면 진단을 새로운 승인 테스트로 편입하는 제안도 아닙니다.

## 이유와 남는 범위

현재 브라우저 제어 도구의 짧은 키 누름은 게임 물리 프레임 동안 WASD를 유지하지 못합니다. 실제 앱 입력을 이용한 대안은 CUA가 Codex 앱 접근을 안전상 거부했습니다. 제한을 우회하지 않았습니다.

장면 진단은 실제 게임 코드에서 세 결말과 상호작용을 실행하지만, 브라우저 공간을 걸어서 탐색한 증거는 아닙니다. 따라서 최종 웹 버전의 전체 동선, 장시간 브라우저 입력·오디오 경험, 공포의 주관적 효과는 보증하지 않습니다. 기존 기준을 유지할 경우 실제 플레이어의 세 경로 확인이 추가로 필요합니다.

## 검토할 산출물

- `QA.md`: 검증 기록과 한계.
- `build/never-sunset-web.zip`: 무료 재질·효과음·미독 자막 보존까지 포함한 웹 빌드.
- `drafts/atmosphere/flow_review.gd`: 승인 수동 기준의 일부를 진단하는 보조 코드.

이 변경은 사용자 승인 전에는 적용하지 않습니다.
